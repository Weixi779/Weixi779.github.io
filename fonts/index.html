字体与许可

本站中文正文与常规界面文字使用霞鹜新晰黑 v1.305， 由 LXGW 基于 IPAexGothic 改作。网站仅保留当前内容用到的字符， 将裁剪后的字体独立命名为 Weixi Sans，字形未作修改。 该字体依照 IPA Font License 1.0 发布。

恢复为原始 IPA 字体

如果你希望使用原始字体，可以从IPA 官方下载页面下载并安装 IPAexGothic（IPAexゴシック），然后重新打开本网站。 浏览器允许访问本地字体时，本站会优先使用它。 原始字体采用日文字形，部分汉字和标点与简体中文写法不同。

也可以在支持自定义字体的浏览器中选择已安装的 IPAexGothic， 并关闭网页指定字体。卸载本地 IPAexGothic、恢复浏览器的网页字体设置后， 本站会重新使用新晰黑。

导航、页脚与代码字体

  • 页脚的「Stay hungry. Stay foolish.」花体落款：Allura Regular，SIL Open Font License 1.1。
  • 页脚版权、许可链接与归档年份导航：Source Sans 3 Regular，SIL Open Font License 1.1。
  • 正文中的英文与代码中的拉丁字符：JetBrains Mono v2.304，SIL Open Font License 1.1。
  • 顶部导航的站名与菜单、Banner 标题与分类、代码中的中文：霞鹜文楷等宽 GB v1.522，SIL Open Font License 1.1。

顶部导航与 Banner 标题、分类使用文楷的常规字重；主题设置面板沿用常规界面字体。 Banner 简介使用 Weixi Sans，首页英文引言与眉题使用 JetBrains Mono。 页脚版权与 Font Licenses 链接使用 Source Sans 3，图标名称提示优先使用系统字体。 上述网页字体均由本站本地提供，许可文件可通过各项链接查看。 Allura 与 Source Sans 3 以 WOFF2 格式压缩传输，保留完整字库、字形与许可信息。
