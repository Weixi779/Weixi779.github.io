热爱也有难以回答的问题

从编程与开源出发，记录热爱、创作与自我安慰，以及那些作出选择以后仍然存在的问题。

本文目录
  1. 做什么
  2. 自我安慰

又一次踏上归乡的路途。这段时间，总在纠结一些想不明白的问题。长途高铁带来的纯净状态可遇而不可求，借这个机会，把这些问题写下来，理一理。

做什么

「焦虑症」是我不想再面对的东西，所以我强迫自己不要空想。未来是由现在一条又一条丝线交织而成的绸缎，不是躺在床上空想出来的。用当前的状态去对抗未来的事情，公式两边本就不可能配平。所以我选择多去实践，多去创造，多去做我喜欢的事情。

比较幸运的是，我的爱好和工作基本重合。我非常享受编程的过程，抽组件，搭架构，写分层，搞模式，做权衡。AI 的到来，让我从机械敲击键盘的人，变成了整支施工队的组织者。这种生产力的解放难以想象，生在这个时代，无比幸运。以前还会根据代码量的多少，纠结谁的贡献更大。现在看来，不过是一些 token 的问题，也确实放下了。

但这份热爱既是祝福，也是诅咒。看到低级的代码，我会骂街骂出声音；看到有意思的代码，也会会心一笑。随时都欢迎有人跟我讨论更高维的设计、抽象问题。可最近发现，随着能力提升，已经把绝大部分人落下了。日常交流里，没人跟我讨论这些问题，谈的都是 API 怎么用、这个命名怎么样、文件夹放哪里，那些完全浮于表面的问题。不是说这些问题不应该存在，只是它们已经完全不能让我提起兴趣了。同龄的也好，比我年长的也好，都是如此。见过的人越多，越能感受到，这个世界上就是凡人居多。

为了不再焦虑，我继续给自己找事情做，把目光放到了开源上。开源是一片非常大的大陆。AI 的出现让做一个库的成本小了很多，但这片大陆上也到处都是历史留下的痕迹。一些曾经常见的库，已经缺少日常维护。以当前的生产力来看，它们做得其实很差。语法糖会过时，编程范式会过时，编程语言会过时，但面对这些抽象问题的解决思路永远不会过时。我摩拳擦掌，想要更新这些实现，创造属于自己的东西，证明我曾经思考过，曾经来过这里。于是写下了一篇又一篇博客，创建了一个又一个仓库，有的是小型概念验证，有的是经验汇总，还有一些是真正能用于生产环境的功能。

你明明知道自己的作品比同类型的东西更好，更现代，更易于扩展。但没用，没有曝光。于是还要证明自己，证明自己做的东西比别人的更好。还要写文章、投稿、找平台曝光，不然仓库里的星星连个位数都超不过。v0，介绍设计思路；v1，介绍功能扩展；v2，介绍架构重构。也许它曾经只是一个简单 API 的二次封装，需要介绍；也许它曾经堆砌了太多功能，需要向外界说清楚。可现在，它已经长成了巨人，可以从中提炼出思想了。你却依然要介绍它、安利它。我曾经剪了一个月的视频，扔到网上无人问津。这无所谓，确实很菜，自娱自乐。可如果真用心做了半年的视频，最后还得在平台上花钱买推流，才能进入大众视野，那我想问，创作者还有什么意义？一句「酒香不怕巷子深」是安慰不了创作者们的。作品怎么被看见，思想怎么被传递，这句话什么都没有解决。一个有热情的人，认真思考，认真做东西，最后依然要面对这些问题。知道自己做得好，也知道自己还会继续做，问题却依然在那里。

于是我又开始行动，想把注意力从编程上挪开，重新拾起绘画、音乐、日语。可这些领域充斥着培训机构的广告，我只想一个人静静地学，于是开始痛苦地自学。自学总有卡壳、进行不下去的时候，而它们又只是爱好，那就先放一放，然后又被搁置。一次又一次地循环。到头来，发现自己最喜欢的还是编程。倘若因为其他事情改变了选择，那我觉得自己也没有那么酷了，这份喜欢也算不上真正的热爱了。也许这是一种宿命论？如果提前把结局告诉梵高，我想，他也会感到遗憾吧，却依然会再次选择这条道路，因为这是真正的热爱。所以，再来多少次，我还是会作出这样的选择。我仍然认为自己在做正确的事情。于是像往常一样，继续写仓库，继续写博客，继续做到极致，继续突破边界，尝试不再在意那件「袈裟」。我当然期望有人能够理解其中的思想。但作品写出来，交出去，之后会被怎样解读，又会走到哪里，已经是作品自己的事情了。作为作者，我也只能走到这里。

只是这一路走下来，自己也确实变了。变得独立，过于独立，变得孤僻、不合群，也没有再那么容易依靠他人。这是一路寻找答案，走到今天的结果。也许这就是诅咒的代价。

自我安慰

「明天会更好。」可是真的会更好吗？我不知道。说出这句话以后，今天想不通的问题依然没有答案，遇到的事情也没有因此改变。这终究只是一句自我安慰。但人又确实需要这样的安慰。明知道没有保证，明天醒来也可能还是要面对同样的事情，有时候依然需要听到一句「明天会更好」。

想到这里，又觉得这大概就是人类。连安慰解决不了问题都想明白了，却依然需要一点安慰。「明天未必会更好。」 但明天到来的时候，我大概还是会继续做我今天愿意做的事情。

来自GPT老师的结语：

别把整个人生都变成“证明我来过”。

代码、文章、repo，当然是痕迹。

但和朋友吃的一顿饭，在高铁上发呆的一下午，听到一首歌突然觉得很好听，某个晚上打了一场很爽的游戏，这些东西不会进入 Git history，也没有 star。

它们依然是人生。
