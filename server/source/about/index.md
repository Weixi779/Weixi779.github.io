Hi，我是孙世伟，一名 iOS 开发者。

从 Flutter、Unity、Objective-C 一路走回 Swift 与 SwiftUI，过去几年做过业务迭代，也做过网络、日志、缓存和富文本等客户端基础设施。环境与产品一直在变，写代码的重心也慢慢从完成功能，走到架构、工程治理与研发流程。比起追逐一个“正确答案”，现在更关心一套系统为什么会变成今天这样，它的边界在哪里，又是否为下一次变化留下了余地。

工作之外，会把反复遇到的问题整理成开源项目。WICompress、Moira，以及一些围绕日志、触觉与并发重试的小工具，大多来自真实项目里的取舍。它们不一定是标准答案，只是希望把当时成立的思考，留成可以被使用、被验证，也可以被后来者替换的东西。

最近也在持续研究 AI 开发工具、Agent 与自动化工作流。工具进步得很快，许多原本漫长的探索正在被压缩；但真正值得留下的，仍然是对问题的理解、做过的选择，以及最终完成的作品。

代码之外，学习一点音乐，也喜欢游戏、影视和那些认真做出来的作品。这个小站会继续记录技术的演化，也留下一些生活经过的痕迹。很多结论都只是当前语境下的选择，有更好的，之后还会改。
